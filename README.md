# OIC Insurer Index: demo

Live demo: https://phasuvut-bot.github.io/oic-insurer-index-demo/

A clickable prototype of an insurer index scored by verified policyholders, proposed to Thailand's
Office of Insurance Commission (OIC, คปภ.).

**All insurer and product names are fictional, and every score, review, person, plate and policy
number is simulated.** Nothing here reflects any real company.

Reviews, points and portal actions you make are saved only in your own browser. Use "Reset demo data"
on the points page to start again. This repository holds only the built demo; the source is private.
